# jQuery-плагин trackCoords

Плагин раз в checkInterval запоминает, где мышь, и раз в sendInterval отправляет накопленное на url. Мышь ловится на всей странице, а x/y считаются от левого верхнего угла элемента: если увести курсор левее рамки, x уйдет в минус, если правее - станет больше ее ширины.

Сам плагин - public/jquery.trackCoords.js, нужен jQuery.

```
<script src="jquery.trackCoords.js"></script>
<script>
    $("div.container").trackCoords({url: '/save.php'});
</script>
```

Настройки:

- checkInterval - период сбора данных в мс, по умолчанию 30
- sendInterval - период отправки в мс, по умолчанию 3000
- url - адрес для отправки, без него плагин ничего не делает

## Данные

Массив точек {x, y, time}, time - сколько миллисекунд курсор провел в точке. Например, [{x: 10, y: 25, time: 90}, {x: 12, y: 25, time: 30}] - мышь 90 мс стояла в (10, 25), потом сдвинулась. Пока мышь стоит, растет time у последней записи. Вернулась позже в старую точку - это уже новая запись, чтобы не терять порядок. Когда курсор за окном или вкладка в фоне, ничего не пишется.

Шлю обычным $.post, массив точек лежит JSON-строкой в поле coords, в PHP это `json_decode($_POST['coords'], true)`.

После отправки буфер чистится. Если запрос не прошел, пачка теряется, повторную отправку не делал.

## Демо

```
docker compose up -d --build
```

Потом открыть http://localhost:8081/ и подвигать мышью, под рамкой выводится последняя отправленная пачка.

Без докера: из папки с решением `php -S localhost:8081 -t public`, дальше так же.

save.php - заглушка только для демо, возвращает то, что получила. По заданию серверная часть не нужна.
