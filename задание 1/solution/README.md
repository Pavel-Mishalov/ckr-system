# Вложенные группы товаров

## Запуск

```
docker compose up -d --build
```

При запуске в контейнере mysql отрабатывают последователь миграции из директории sql.
1) 1_base.sql - Вводные данные созданных таблиц и данных в этих таблицах
2) 2_update_consistency - Рефакторинг схемы базы данных для обеспечения ссылочной целостности (Referential Integrity), оптимизации транзакционной нагрузки и подготовки архитектуры к иерархическим запросам.
Здесь идет смена движка наблиц на InnoDB. MyISAM не поддерживает внешние ключи (FOREIGN KEY) и блокирует таблицы целиком при любой записи (Table-level locking).
Переход дает полную поддержку ACID-транзакций, строковые блокировки (для увеличения производительности), поддержку физ. связей между таблицами.
Добавлена нормализация связей и обработка корневых категорий как null значение.
Внедрение внешних ключей для консистентности данных.
3) Добавлена вспомогательная таблица group_tree(parent_id, child_id, depth) для быстрого поиска
по деревьям групп. Также запуск начального наполнения по имеющимся уже данным.
4) Добавления триггеров для наполнения таблицы дерева групп, при взаимодействии с таблицей groups.
В момент удаления - записи удаляются по внешним ключам автоматически.
При создании - срабатывает триггер after_category_insert в котором создаются новые записи по дереву категорий
При обновлении - триггер выдает ошибку, из обратного обращения к таблице groups при проверке внешних ключей. Поэтому создана процедура move_group, с помощью которой изменяем все необходимые связи дерева и обновляем для переданной категории/переданного родителя

Для вывода данных добавлены методы getProduct и getGroupTree.

getProduct - запрашивает все продукты, которые находятся в заданной группе или ее дочерних группах
```sql
SELECT name, id
FROM products
-- оставляем только продукты, где группа соответствует дочерней группе от целевой
WHERE exists(
    select 1 from group_tree
    where group_tree.child_id = products.id_group and group_tree.parent_id = :group_id
)
ORDER BY name
```

getGroupTree - возвращает дерево заданных по условию групп и кол-во продуктов в этой и его дочерних группах
```sql
select
    id,
    name,
    id_parent,
    -- возвращаем кол-во продуктов из групп, для которох данная является родителем
    (select count(1) from products where products.id_group in (select group_tree.child_id from group_tree where group_tree.parent_id = `groups`.id)) as num
from `groups`
where
    -- Корневые группы всегда выводим
    id_parent is NULL
OR
    -- Выводим всех родителей целевой, т.е. всю цепочку групп от целевой от корневой группы
    exists(
        select 1 from group_tree where child_id = :active and group_tree.parent_id = `groups`.id
    )
OR
    -- Выводим все дочерние группы целевой
    exists(
        select 1 from group_tree where child_id = `groups`.id and group_tree.parent_id = :active and depth = 1
    )
```

Для вывода контента взят шаблонизатор twig.

Доступ для просмотра http://localhost:8080/
